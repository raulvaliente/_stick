# ChatGPT · Chats rápidos

## Escritorio

| Atajo | Acción |
| :--- | :--- |
| `Ctrl+Shift+P` | Abrir el menú de comandos |
| `Ctrl+N` | Empezar un chat nuevo |
| `Ctrl+Alt+N` | Abrir un chat rápido |
| `Ctrl+F` | Buscar dentro del chat abierto |

## Web

| Atajo | Acción |
| :--- | :--- |
| `Ctrl+K` | Buscar chats y otros contenidos |

> ==Recupera un chat== buscando un nombre de archivo o una frase del error que pegaste.
