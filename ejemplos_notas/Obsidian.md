# Obsidian · Encuentra tus notas

| Atajo | Acción |
| :--- | :--- |
| `Ctrl+O` | Abrir nota por nombre o alias |
| `Ctrl+P` | Abrir la paleta de comandos |
| `Ctrl+Shift+F` | Buscar en toda la bóveda |
| `Ctrl+Enter` | Abrir un resultado de `Ctrl+O` en otra pestaña |
| Escribe `[[` | Insertar un enlace a otra nota |

> ==Vuelve a la nota anterior== con `Ctrl+O`, luego `↓` y `Enter` sin escribir nada.

[Selector rápido de Obsidian](https://obsidian.md/help/plugins/quick-switcher)
