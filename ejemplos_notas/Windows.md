# Windows · Cambia de contexto

| Atajo | Acción |
| :--- | :--- |
| `Alt+Tab` | Cambiar de ventana |
| `Win+←` / `Win+→` | Acoplar a media pantalla |
| `Win+1` a `Win+9` | Abrir o activar una app de la barra de tareas |
| `Win+Tab` | Ver ventanas y escritorios |
| `Win+Ctrl+D` | Crear un escritorio virtual |
| `Win+Ctrl+←` / `Win+Ctrl+→` | Cambiar de escritorio virtual |

> ==Salta del editor al navegador== con `Win+1` y `Win+2` tras anclarlos en las dos primeras posiciones de la barra.

[Más atajos de Windows](https://support.microsoft.com/en-us/accessibility/windows/keyboard-shortcuts-in-windows)
