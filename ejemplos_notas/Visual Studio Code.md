# VS Code · Navegación

| Atajo | Acción |
| :--- | :--- |
| `Ctrl+P` | Abrir archivo por nombre |
| `Ctrl+Shift+P` | Buscar un comando |
| `Ctrl+Shift+F` | Buscar texto en el proyecto |
| `Ctrl+Shift+O` | Ir a una función o clase del archivo |
| `F12` | Ir a la definición |
| `Alt+←` | Volver a la ubicación anterior |
| `Ctrl+Tab` | Cambiar de archivo dentro del grupo |

> ==Sigue una llamada== con `F12` y vuelve al punto de partida con `Alt+←`.

[Más atajos de VS Code](https://code.visualstudio.com/docs/reference/default-keybindings)
