# Chrome · Pestañas y DevTools

| Atajo | Acción |
| :--- | :--- |
| `Ctrl+L` | Ir a la barra de direcciones |
| `Ctrl+Tab` | Pasar a la siguiente pestaña |
| `Ctrl+1` a `Ctrl+8` | Saltar a una pestaña por posición |
| `Ctrl+9` | Saltar a la última pestaña |
| `Ctrl+Shift+T` | Reabrir la última pestaña cerrada |
| `Ctrl+Shift+R` | Recargar sin usar la caché |
| `Ctrl+Shift+J` | Abrir la consola de DevTools |

> ==Conserva la página actual== con `Ctrl+L`, escribe la consulta y pulsa `Alt+Enter` para buscar en otra pestaña.

[Atajos de Chrome](https://support.google.com/chrome/answer/157179) · [Atajos de DevTools](https://developer.chrome.com/docs/devtools/shortcuts)
