# PyCharm · Navegación

| Atajo | Acción |
| :--- | :--- |
| `Shift` dos veces | Buscar archivos, clases y acciones |
| `Ctrl+Shift+A` | Buscar un comando |
| `Ctrl+E` | Abrir archivos recientes |
| `Ctrl+B` | Ir a la declaración o a sus usos |
| `Alt+F7` | Listar los usos del símbolo |
| `Alt+Enter` | Ver las acciones del cursor |

> ==Retoma la edición== con `Ctrl+Shift+Retroceso` para volver al último punto que editaste.

[Más atajos de PyCharm](https://www.jetbrains.com/help/pycharm/keymap-reference.html)
